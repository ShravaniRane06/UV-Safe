# UV-Safe
A full-stack UV Index web application that provides real-time UV levels, personalized safety recommendations, and location-based forecasts using the OpenUV API.
Users can either use their current location or manually enter coordinates to receive real-time UV data powered by the OpenUV API.

---

# Features

- 📍 Check UV Index using your current location
- 🌍 Enter latitude and longitude manually
- ☀️ Real-time UV Index using the OpenUV API
- 🧴 Personalized sun protection recommendations
- 🌙 Light/Dark mode toggle
- 📱 Responsive design for desktop and mobile devices
- ❓ Interactive FAQ section with expandable answers
- 🖼️ Modern UI with Bootstrap and custom CSS

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/uvsafe.git
```

Navigate into the project

```bash
cd uvsafe
```

Install dependencies

```bash
npm install
```

Create a `.env` file in the project root

```env
API_KEY=YOUR_OPENUV_API_KEY
```

Start the server

```bash
node index.js
```

Visit

```
http://localhost:3000
```

# 📋 How It Works

1. Open the application.
2. Choose one of the following:
   - Use Current Location
   - Enter Latitude & Longitude Manually
3. The application requests UV data from the OpenUV API.
4. The UV Index is displayed along with:
   - UV Risk Level
   - Safety Recommendations
5. Users can switch between Light and Dark mode.
